Place the hero loop and brand film in this directory, then set the matching URL in src/lib/content.ts.

Recommended:
- hero.mp4: muted, 8–15 seconds, H.264, portrait or centre-safe framing, ideally under 5 MB.
- orthotrack-story.mp4: landscape H.264 film with spoken content captioned in the video, or add a WebVTT track in the StoryPlayer component.

Files are not loaded unless their URL is configured. The supplied images remain useful poster fallbacks.
